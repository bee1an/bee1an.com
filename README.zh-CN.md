# Vitesse Lite

基于 [Vitesse Lite](https://github.com/antfu-collective/vitesse-lite) 的轻量 Vue 项目模板。

## 本地开发

```bash
pnpm install
pnpm dev
```

## 常用命令

```bash
pnpm build
pnpm lint
pnpm typecheck
pnpm test
```

## 部署

`main` 分支会通过 `pnpm build` 自动构建，并部署到 Cloudflare Pages：
[bee1an.com](https://bee1an.com)。
