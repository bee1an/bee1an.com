# Vitesse Lite

A lightweight Vue starter based on [Vitesse Lite](https://github.com/antfu-collective/vitesse-lite).

## Development

```bash
pnpm install
pnpm dev
```

## Commands

```bash
pnpm build
pnpm lint
pnpm typecheck
pnpm test
```

## Deployment

The `main` branch is automatically built with `pnpm build` and deployed to
Cloudflare Pages at [bee1an.com](https://bee1an.com).
